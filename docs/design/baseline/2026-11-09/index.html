  2. Extract MediaHero, ContentRow, SectionHeader, MediaGallery, StatusText; Program page consumes them with no visual change.
  3. Discover + My Programs: page--content / page--wide, ContentRow on mobile My Programs, status tokens, one type scale. Replaces program-library.css breakpoints 680/850/1150.
  4. Activity + Group: content width, MediaHero-lite header, fewer panels, MediaGallery for Related Media.
  5. Calendar + Editor: status tokens on tiles, fix the overhanging More button, editor on page--focused for all four steps, 16:9 cover upload.
